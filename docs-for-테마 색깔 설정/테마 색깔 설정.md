# 관련 파일 구조

```
stay-ops-front/
├── src/
│   ├── index.css                          # 5개 테마의 CSS 변수(팔레트) 정의 + 배경 그라데이션
│   └── shared/
│       ├── stores/
│       │   └── theme-store.ts             # Zustand 테마 상태 (persist 로 localStorage 저장)
│       ├── layouts/
│       │   └── app-shell.tsx              # <html> 에 data-theme 속성을 적용하는 진입점
│       └── ui/
│           └── theme-toggle.tsx           # 테마 선택 드롭다운(스와치 미리보기 포함)
└── vite.config.ts                         # Tailwind v4 플러그인 로드 (별도 tailwind.config 없음)
```

핵심 아이디어는 **Tailwind v4 + CSS 변수** 조합입니다. 색상 팔레트는 모두 CSS 커스텀 프로퍼티(`--background`, `--foreground`, `--accent` …)로 선언하고, 컴포넌트는 `bg-[var(--surface)]` 처럼 변수를 그대로 읽어 씁니다. 테마 전환은 `<html data-theme="ocean">` 속성만 바꾸면 `:root[data-theme="..."]` 블록이 활성화되어 팔레트가 통째로 교체됩니다.

# 주요 설정 코드

## 1. 팔레트 정의 — `stay-ops-front/src/index.css`

5개 테마(`light` / `dark` / `sepia` / `ocean` / `forest`)를 전부 CSS 변수로 선언합니다. 아래는 지금 보이는 **ocean(네이비 + 틸)** 테마입니다.

```css
:root[data-theme="ocean"] {
  color-scheme: dark;
  --background: #0b1c2c;                  /* 짙은 네이비 배경 */
  --foreground: #e8f1f8;                  /* 본문 텍스트 */
  --muted:      #8ea8be;                  /* 보조 텍스트 */
  --surface:        rgba(18, 38, 58, 0.88);   /* 카드/헤더 표면 */
  --surface-strong: #14304a;
  --border:     rgba(180, 210, 235, 0.14);
  --accent:        #3fa7d6;               /* 포인트(틸 블루) */
  --accent-strong: #a5d8f0;
  --ring:          rgba(63, 167, 214, 0.34);  /* 포커스 링 */
  --control:        rgba(22, 46, 70, 0.88);
  --control-hover:  rgba(30, 60, 90, 0.96);
  --control-active: linear-gradient(135deg, #3fa7d6 0%, #1e5d88 100%);
}
```

배경의 "은은한 빛망울" 효과는 `html` 태그에 얹힌 두 개의 `radial-gradient`에서 나옵니다.

```css
html {
  background:
    radial-gradient(circle at top left,  rgba(210, 106,  44, 0.18), transparent 28%),
    radial-gradient(circle at top right, rgba( 53, 106, 168, 0.16), transparent 26%),
    var(--background);
}

body::before {
  /* 24px 격자 오버레이 — 화면 전체에 얇은 그리드 느낌을 줌 */
  background-image:
    linear-gradient(rgba(255,255,255,0.03) 1px, transparent 1px),
    linear-gradient(90deg, rgba(255,255,255,0.03) 1px, transparent 1px);
  background-size: 24px 24px;
}
```

## 2. 테마 상태 — `stay-ops-front/src/shared/stores/theme-store.ts`

Zustand + `persist` 미들웨어로 선택한 테마를 `stay-ops-theme` 키로 localStorage 에 저장합니다.

```ts
export type Theme = 'light' | 'dark' | 'sepia' | 'ocean' | 'forest'
export const THEMES: Theme[] = ['light', 'dark', 'sepia', 'ocean', 'forest']

export const useThemeStore = create<ThemeStore>()(
  persist(
    (set, get) => ({
      theme: 'light',
      setTheme: (theme) => set({ theme }),
      cycleTheme: () => {
        const index = THEMES.indexOf(get().theme)
        set({ theme: THEMES[(index + 1) % THEMES.length] })
      },
    }),
    { name: 'stay-ops-theme' },
  ),
)
```

## 3. DOM 적용 — `stay-ops-front/src/shared/layouts/app-shell.tsx`

스토어의 `theme` 값을 `<html>` 의 `data-theme` 속성으로 흘려보내는 한 줄이 핵심입니다. 이 속성이 바뀌는 순간 `:root[data-theme="..."]` 블록이 활성화되어 전체 팔레트가 교체됩니다.

```tsx
const theme = useThemeStore((state) => state.theme)

useEffect(() => {
  document.documentElement.dataset.theme = theme
}, [theme])
```

## 4. 선택 UI — `stay-ops-front/src/shared/ui/theme-toggle.tsx`

드롭다운에 실제 배경색을 그대로 보여주기 위해 JS 쪽에도 대표색 스와치 맵을 둡니다(순수 장식용).

```tsx
const THEME_SWATCHES: Record<Theme, string> = {
  light:  '#f3efe6',
  dark:   '#161311',
  sepia:  '#f4ecd8',
  ocean:  '#0b1c2c',
  forest: '#12201a',
}
```

선택 시에는 `setTheme(t_id)` 만 호출하면 되고, 실제 색상 전환은 위 3번의 `useEffect` 가 처리합니다.
