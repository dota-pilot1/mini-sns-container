## 새 언어를 추가할 때 수정할 곳

예를 들어 프랑스어 `fr`를 추가한다면 아래 순서로 보면 됩니다.

1. `shared/i18n/resources/fr/` 폴더를 만듭니다.
2. `common.ts`, `nav.ts`, `home.ts`, `auth.ts`, `form.ts`를 추가합니다.
3. `shared/i18n/resources/fr/index.ts`에서 namespace를 묶습니다.
4. `shared/i18n/index.ts`에 `fr` import 및 `resources` 등록을 추가합니다.
5. 필요하면 `language-select.tsx`의 선택 목록에도 `FR`을 추가합니다.
