# 셀렉트 박스로 다국어 설정 하는 시나리오 예시

## 핵심 흐름

- 앱 시작 시:
  - `localStorage`에 저장된 언어를 읽어서 초기 언어로 사용
- 셀렉트 박스 변경 시:
  - `i18n.changeLanguage(locale)`로 현재 화면 언어를 즉시 변경
  - `localStorage`에 저장해서 다음 접속 때도 유지

---

## 앱 시작 시 예시

```ts
const storedLocale = localStorage.getItem('locale') ?? 'ko'

void i18n.use(initReactI18next).init({
  resources,
  lng: storedLocale,
  fallbackLng: 'en',
  defaultNS: 'common',
  ns: ['common', 'nav', 'home', 'auth', 'form'],
  interpolation: {
    escapeValue: false,
  },
})
```

의미:
- 저장된 언어가 있으면 그 값을 사용
- 없으면 기본값 `ko` 사용

---

## 셀렉트 박스 변경 시 예시

```ts
const { i18n } = useTranslation()

const handleChange = async (locale: string) => {
  await i18n.changeLanguage(locale)
  localStorage.setItem('locale', locale)
}
```

의미:
- 사용자가 언어를 바꾸면 화면을 즉시 변경
- 변경된 언어를 저장해서 새로고침 후에도 유지

---

## 중요한 포인트

- `localStorage.setItem(...)`만으로는 현재 화면 언어가 바로 바뀌지 않습니다.
- 현재 화면을 즉시 바꾸는 것은 `i18n.changeLanguage(...)`입니다.
- `localStorage`는 다음 앱 시작 시 초기 언어를 결정하는 용도입니다.

---

## 한 줄 정리

셀렉트 박스에서 언어를 바꿀 때는 `changeLanguage()`로 즉시 반영하고, `localStorage`에는 다음 접속 때도 같은 언어를 유지하기 위해 저장합니다.
