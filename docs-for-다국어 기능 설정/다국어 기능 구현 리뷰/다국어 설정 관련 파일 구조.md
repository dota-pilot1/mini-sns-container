## 각 구조 의미

### `main.tsx`

- 앱 시작점
- `@/shared/i18n`을 불러와 다국어를 초기화함

### `shared/i18n/index.ts`

- 다국어 설정 파일
- 지원 언어와 기본 설정을 등록함

### `shared/i18n/resources/<locale>/index.ts`

- 언어별 번역 묶음 파일
- 각 namespace 파일을 모아 export 함

### `shared/i18n/resources/<locale>/common.ts`

- 공통 문구 모음

### `shared/i18n/resources/<locale>/nav.ts`

- 네비게이션 문구 모음

### `shared/i18n/resources/<locale>/home.ts`

- 홈 화면 문구 모음

### `shared/i18n/resources/<locale>/auth.ts`

- 인증 화면 문구 모음

### `shared/i18n/resources/<locale>/form.ts`

- 폼 문구 모음

### `shared/ui/language-select.tsx`

- 언어 선택 UI
- 선택한 언어로 현재 언어를 변경함

### `routes/*.tsx`, `layouts/*.tsx`, `ui/*.tsx`

- 실제 번역 문구를 사용하는 화면 파일
- `useTranslation()`과 `t('...')`로 텍스트를 가져다 씀

## 흐름을 한 줄로 정리

1. `main.tsx`에서 `shared/i18n/index.ts`를 불러 초기화합니다.
2. `shared/i18n/index.ts`가 언어별 리소스와 namespace를 등록합니다.
3. 각 컴포넌트는 `useTranslation()`으로 필요한 문구를 가져다 씁니다.
4. `language-select.tsx`에서 `changeLanguage()`를 호출하면 현재 화면 언어가 바뀝니다.
