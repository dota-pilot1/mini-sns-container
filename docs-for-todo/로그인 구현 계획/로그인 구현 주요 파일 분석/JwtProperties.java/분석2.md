# 핵심 구문2:
===================================================================
this.ttlSeconds = properties.accessTokenTtlSeconds();
this.issuer = properties.issuer();
this.clock = clock;
===================================================================

Step1:
===================================================================
this.ttlSeconds = properties.accessTokenTtlSeconds();
===================================================================
yaml 의 `app.jwt.access-token-ttl-seconds` 값(초)을 필드에 저장.
→ 토큰 발급 시 `exp = now + ttlSeconds` 계산에만 쓰임.
→ v1 기준 1800초 (30분). 만료 지나면 파서가 ExpiredJwtException 던짐.

Step2:
===================================================================
this.issuer = properties.issuer();
===================================================================
yaml 의 `app.jwt.issuer` 값("stay-ops")을 필드에 저장.
→ 토큰의 `iss` 클레임에 박히는 발급자 식별자.
→ "이 토큰은 어느 서비스가 발급했나" 를 밝히는 메타데이터.

Step3:
===================================================================
this.clock = clock;
===================================================================
Spring 이 주입한 `Clock` 빈을 필드에 저장 (ApplicationConfig.clock()).
→ 발급: `Instant.now(clock)` 으로 "지금" 을 얻어 iat/exp 계산
→ 검증: JJWT 파서에도 이 clock 을 넘겨서 만료 판정 기준을 일치시킴
→ 테스트에서 `Clock.fixed(...)` 로 교체 가능 → 만료 시나리오를 결정적으로 테스트
===================================================================
yaml 설정값(ttl, issuer)과 시간 소스(clock)를 필드로 끌어와서,
이후 issue/verify 에서 "얼마나 살리고", "누가 발급했고", "지금이 언제인지" 에 사용
===================================================================
