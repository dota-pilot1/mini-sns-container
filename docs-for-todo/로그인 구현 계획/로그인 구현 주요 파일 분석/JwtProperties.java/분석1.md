# 핵심 구문1:
===================================================================
byte[] secretBytes = properties.secret().getBytes(StandardCharsets.UTF_8);
this.key = Keys.hmacShaKeyFor(secretBytes);
===================================================================

step1:
===================================================================
properties.secret().getBytes(StandardCharsets.UTF_8)
===================================================================
# 풀어서 쓰면
String secret = properties.secret();                        // String 반환
byte[] secretBytes = secret.getBytes(UTF_8);      // String 메서드 호출 UTF-8 스타일로 인코딩
===================================================================
나중에 암호화에 사용하기 위해 jwt 시크릿 키를 읽어 와서 인코딩해서 변수에 담은뒤 이후에 jwt 서명에 활용 
===================================================================

Step2:
===================================================================
this.key = Keys.hmacShaKeyFor(secretBytes);
===================================================================

JJWT 의 Keys.hmacShaKeyFor(byte[]) 에 넘김. 이 메서드가:
* 바이트 길이가 32 이상인지 체크 (HS256 요구사항)
* 통과하면 SecretKey 객체로 감싸서 리턴
* 이후 서명/검증 때 이 SecretKey 가 실제 HMAC 계산에 쓰임.
===================================================================
