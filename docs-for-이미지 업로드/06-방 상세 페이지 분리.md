# 06. 방 상세: 드로어 → 별도 페이지로 분리

## 목표
지금은 드로어(팝업) 로만 있는 방 상세를 `/rooms/:roomId` 페이지로 분리.
드로어는 "빠른 미리보기" 용으로 남기되, "전체 화면 보기" 버튼으로 페이지 이동 가능하게.

## 라우팅
- 추가: `/rooms/:roomId` (protected)
- 기존 `/rooms` 목록은 유지
- 드로어 헤더에 "전체 화면 →" 버튼 → `navigate(/rooms/${roomId})`

## 파일 구조
```
stay-ops-front/src/pages/
├── rooms-page.tsx              (기존 목록)
└── room-detail-page.tsx        (신규)

stay-ops-front/src/features/room/ui/
├── room-detail-panel.tsx       (기존 드로어 콘텐츠에서 분리)
│   └── 드로어와 페이지 양쪽에서 재사용
└── ...
```

## 레이아웃 (detail page)
```
┌─────────────────────────────────────────┐
│ [← 목록]  602호 · 6층                    │
├──────────────────┬──────────────────────┤
│                  │ 기본 정보            │

│  (07 에서 구현)   │ 입주자               │
│                  │ 액션 (수정/삭제)     │
│                  │                      │
└──────────────────┴──────────────────────┘
```

2열 그리드. 모바일에선 세로 스택.

## 데이터 로딩
- `useRoomDetail(roomId)` 훅 (없으면 신규) — 기존 목록 쿼리와는 별개 키 `['rooms', roomId]`
- `useRoomImages(roomId)` 병행 호출
- 로딩 중엔 스켈레톤, 404 는 "해당 방을 찾을 수 없습니다" 빈 상태

## 드로어와의 공통화
`<RoomDetailPanel roomId={...} compact={true|false} />` 한 컴포넌트로 통일:
- `compact=true`: 드로어에서 쓰는 간소화 뷰
- `compact=false`: 전체 페이지에서 쓰는 풀 뷰 (갤러리 크게)

## 완료 기준
- 목록에서 카드 클릭 → 드로어 표시 (기존 동작 유지)
- 드로어의 "전체 보기" → URL 바뀌고 페이지 로드
- 페이지 새로고침해도 상세가 정상 렌더
- 브라우저 뒤로가기로 목록 복귀

## 기타
- **이 스텝에서는 이미지 관련 UI 는 placeholder** ("갤러리 영역") 로 두고, 07 에서 채움
- 페이지 분리만 먼저 끝내면 PR 단위가 작아짐
