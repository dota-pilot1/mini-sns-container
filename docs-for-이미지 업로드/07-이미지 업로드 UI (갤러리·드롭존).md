# 07. 이미지 업로드 UI — 드롭존 + 갤러리

## 목표
방 상세 페이지에 드래그앤드롭 업로드 + 썸네일 갤러리 + 대표 지정 + 삭제.

## 컴포넌트 분할

```
<RoomImageSection roomId>
├── <RoomImageDropzone roomId />        // 업로드 진입점
└── <RoomImageGallery roomId>           // 조회/조작
    ├── <RoomImageThumb image />   ×N
    └── <RoomImageEmptyState />
```

## 드롭존 (`RoomImageDropzone`)
- `react-dropzone` 또는 가벼운 자체 구현
- 허용: `image/*`, 10MB, 최대 10장 동시
- 파일 선택 → `useUploadRoomImage` 호출 × 파일 수 (병렬)
- 상태
  - idle: "이미지를 드래그하거나 클릭해 업로드" 점선 박스
  - dragging: 하이라이트
  - uploading: "N / M 업로드 중..." + 스피너
  - error: 실패 파일명 토스트

## 썸네일 (`RoomImageThumb`)
- 정사각 썸네일 (aspect-square)
- 호버 시 반투명 오버레이 + 액션
  - ⭐ 대표 지정 (`useSetPrimaryRoomImage`)
  - 🗑 삭제 (`useDeleteRoomImage`) — confirm 먼저
- 대표 이미지는 좌상단 배지 "대표"

## 갤러리 (`RoomImageGallery`)
- CSS grid, `minmax(120px, 1fr)` 반응형
- 비어 있을 때: "등록된 이미지가 없습니다. 위 영역에 드롭하세요." 문구
- 정렬: `sortOrder ASC` (서버 반환 순서 그대로)
- 순서 변경(드래그 재정렬)은 **이 스텝에 포함 안 함** — 필요 시 후속 스텝

## 접근성
- 드롭존 `role="button"`, 키보드 Enter/Space 로 파일 선택 트리거
- 썸네일 `alt` = `"{방번호} 이미지 {index+1}"`
- 삭제 버튼은 항상 DOM 에 있되 시각적으로만 호버 노출 (키보드 focus 시 보이게)

## 다크 모드
- 테마 토큰만 쓰고, 하드코딩된 색 금지
- 오버레이는 `bg-foreground/60` 같은 시맨틱 토큰

## 에러 케이스
- presign 실패 → "업로드 준비 실패" 토스트
- S3 PUT 실패 (CORS·네트워크) → 해당 파일만 실패 표시
- register 실패 → S3 객체는 남음 (04 의 클린업 이슈와 연결)

## 완료 기준
- 여러 장 한 번에 드롭 → 전부 썸네일로 보임
- 대표 지정 → 배지 이동, 네트워크 1회
- 삭제 → confirm 후 썸네일 사라짐, 대표였다면 자동 승격 반영
- 업로드 중 페이지 이탈해도 다른 탭에서 돌아오면 최신 상태
