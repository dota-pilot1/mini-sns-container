# Tailwind 의 arbitrary value (임의값) 문법

구조 뜯어보기
border-[var(--border)]
│     │└────────────┘
│     │     ↑
│     │     값(value) — 대괄호 안에 임의의 CSS 값을 넣을 수 있음
│     └ 대괄호 = "arbitrary value" 신호
└ 유틸리티 prefix (= CSS 속성 매핑)
