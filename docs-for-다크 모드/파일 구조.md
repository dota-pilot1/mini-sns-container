# 파일 구조

## 핵심 파일

```text
stay-ops-front/
├── src/
│   ├── index.css
│   └── shared/
│       ├── layouts/
│       │   └── app-shell.tsx
│       ├── stores/
│       │   └── theme-store.ts
│       └── ui/
│           └── theme-toggle.tsx
```

## 파일별 역할

### `/Users/terecal/stay-ops-container/stay-ops-front/src/shared/stores/theme-store.ts`

- 다크 모드 상태 저장소입니다.
- `zustand` + `persist` 로 `theme` 값을 관리합니다.
- 값은 `'light' | 'dark'` 두 가지입니다.
- 기본값은 `light` 입니다.
- `toggleTheme()` 으로 현재 값을 반대로 바꿉니다.
- `localStorage` 에 `stay-ops-theme` 키로 저장됩니다.

### `/Users/terecal/stay-ops-container/stay-ops-front/src/shared/layouts/app-shell.tsx`

- 저장된 테마를 실제 DOM에 반영하는 파일입니다.
- `useThemeStore` 로 현재 `theme` 값을 읽습니다.
- `useEffect` 에서 `document.documentElement.dataset.theme = theme` 를 실행합니다.
- 결과적으로 `<html data-theme="light">` 또는 `<html data-theme="dark">` 형태가 됩니다.
- 헤더 우측에 `ThemeToggle` 이 배치되어 있습니다.

### `/Users/terecal/stay-ops-container/stay-ops-front/src/shared/ui/theme-toggle.tsx`

- 다크 모드 전환 버튼 UI 입니다.
- 현재 `theme` 와 `toggleTheme` 액션을 store에서 가져옵니다.
- 클릭하면 `onClick={toggleTheme}` 로 즉시 전환됩니다.
- 현재 상태에 따라 버튼 텍스트와 원형 표시 색상이 바뀝니다.

### `/Users/terecal/stay-ops-container/stay-ops-front/src/index.css`

- 라이트/다크 테마 색상 토큰이 정의된 전역 스타일 파일입니다.
- `:root` 에 라이트 모드 변수들이 있습니다.
- `:root[data-theme="dark"]` 에 다크 모드 변수들이 있습니다.
- `html[data-theme="dark"]` 가 적용되면 CSS 변수 세트가 다크용으로 바뀝니다.
- `color-scheme: light` / `color-scheme: dark` 도 함께 변경됩니다.

## 실제 동작 흐름

1. 앱 시작 시 `theme-store.ts` 가 `stay-ops-theme` 값을 복원합니다.
2. `app-shell.tsx` 가 현재 `theme` 값을 읽습니다.
3. `useEffect` 가 `<html>` 에 `data-theme` 값을 넣습니다.
4. `index.css` 의 `:root` 또는 `:root[data-theme="dark"]` 규칙이 적용됩니다.
5. 화면 전체에서 사용하는 CSS 변수 색상이 바뀝니다.
6. 사용자가 `theme-toggle.tsx` 버튼을 누르면 다시 같은 흐름으로 갱신됩니다.

## 구현 잘못된점

- 시스템 테마 연동이 없습니다. `prefers-color-scheme` 를 읽지 않아서 OS 다크 모드를 자동으로 따라가지 않습니다.
- `system` 옵션이 없습니다. 현재는 `light`, `dark` 두 값만 있어서 사용자 선택 폭이 좁습니다.
- 초기 렌더 타이밍이 약간 아쉽습니다. `data-theme` 를 React `useEffect` 에서 넣기 때문에 첫 렌더 순간에는 기본 라이트 스타일이 먼저 보일 가능성이 있습니다.
