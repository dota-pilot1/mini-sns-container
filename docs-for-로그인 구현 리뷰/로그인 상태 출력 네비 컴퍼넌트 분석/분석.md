# 핵심 구문: UserMenu (아바타 + 드롭다운)
===================================================================
로그인 상태일 때 네비 우측에 이니셜 원형 아바타를 표시.
클릭하면 드롭다운이 열리고 이름/이메일/로그아웃 버튼이 보인다.
비로그인이면 아바타 대신 [로그인] [회원가입] pill 이 표시됨.
===================================================================


Step1: 로그인 여부에 따른 분기 (AppShell)
===================================================================
const user = useAuthStore((s) => s.user)

{user ? (
  <UserMenu name={user.name} email={user.email} onLogout={handleLogout} />
) : (
  <>
    <NavLink to="/login">로그인</NavLink>
    <NavLink to="/signup">회원가입</NavLink>
  </>
)}
===================================================================
useAuthStore 에서 user 를 구독.
→ user 가 있으면 (로그인 상태) → UserMenu 렌더
→ user 가 null 이면 (비로그인) → 로그인/회원가입 링크 렌더
→ 로그아웃 시 clear() 가 user 를 null 로 만들어 자동 전환.


Step2: 이니셜 아바타 버튼
===================================================================
const initials = name
  .split(/\s+/)
  .map((w) => w[0])
  .join('')
  .toUpperCase()
  .slice(0, 2)

<button onClick={() => setOpen((v) => !v)}>
  {initials}
</button>
===================================================================
이름에서 이니셜 추출:
→ "오현석" → split → ["오현석"] → 첫글자 → "오" → slice(0,2) → "오"
→ "Alice Kim" → split → ["Alice","Kim"] → 첫글자 → "AK"
→ accent 배경 + 흰 글씨의 원형 버튼. 클릭하면 open 토글.


Step3: 드롭다운 (이름 + 이메일 + 로그아웃)
===================================================================
{open ? (
  <div className="absolute right-0 top-12 ...">
    <div>              ← 상단: 이름 + 이메일
      <p>{name}</p>
      <p>{email}</p>
    </div>
    <button onClick={onLogout}>  ← 하단: 로그아웃 (빨간색)
      <LogoutIcon />
      로그아웃
    </button>
  </div>
) : null}
===================================================================
open 이 true 일 때만 렌더. absolute 로 아바타 아래에 위치.
→ 상단: 이름(볼드) + 이메일(회색 작은 글씨) → 누구인지 확인용
→ 하단: 로그아웃 버튼. 빨간 텍스트 + 문 아이콘. 클릭 시 clear + /login 이동.


Step4: 외부 클릭 시 닫기
===================================================================
useEffect(() => {
  if (!open) return
  function handleClick(e: MouseEvent) {
    if (ref.current && !ref.current.contains(e.target as Node)) {
      setOpen(false)
    }
  }
  document.addEventListener('mousedown', handleClick)
  return () => document.removeEventListener('mousedown', handleClick)
}, [open])
===================================================================
드롭다운이 열린 상태에서 바깥 아무 데나 클릭하면 자동으로 닫힘.
→ ref 로 UserMenu 전체 div 를 감싸고, 클릭 대상이 그 안이 아니면 닫기.
→ open 이 false 면 이벤트 리스너 자체를 안 걺 → 불필요한 리스너 방지.
→ cleanup 에서 removeEventListener → 메모리 누수 방지.


Step5: 로그아웃 동작
===================================================================
const handleLogout = () => {
  clearAuth()                   // auth-store clear → accessToken=null, user=null
  navigate({ to: '/login' })    // /login 으로 이동
}
===================================================================
→ clearAuth() 가 localStorage 의 'stay-ops-auth' 도 같이 제거 (persist 미들웨어)
→ user 가 null 이 되면서 AppShell 이 자동으로 로그인/회원가입 pill 로 전환
→ 라우트 가드(requireAuth) 가 토큰 없음을 감지 → 보호 페이지 재접근 시 /login 리다이렉트
→ v1 은 서버에 로그아웃 API 호출 없음 (블랙리스트는 v2)
===================================================================

"아바타 클릭 → 드롭다운에 이름/이메일/로그아웃 표시.
 로그아웃은 스토어 clear 한 방이면 프론트 전체가 비로그인 상태로 전환."
