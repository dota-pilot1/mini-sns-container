# 등록된 다국어를 어떻게 가져다 쓰나

## 핵심 한 줄

등록된 다국어는 `main.tsx`에서 i18n을 한 번 초기화한 뒤, 각 컴포넌트에서 `useTranslation()`으로 가져다 씁니다.

즉:
- 초기화는 앱 시작 시 한 번
- 실제 사용은 각 컴포넌트에서 `t('namespace:key')`

## 초기화 과정

### 1. `main.tsx`에서 i18n import

- [main.tsx](/Users/terecal/mini-sns-conainer/mini-sns-front/src/main.tsx)

```ts
import '@/shared/i18n'
```

이 코드는 값을 받아서 쓰는 import가 아니라, `초기화 코드를 실행시키는 import`입니다.

효과:
- 앱 시작 시 i18n 설정 파일이 실행됨
- 언어 리소스가 메모리에 등록됨
- React와 i18n이 연결됨

### 2. 실제 초기화는 `src/shared/i18n/index.ts`

- [index.ts](/Users/terecal/mini-sns-conainer/mini-sns-front/src/shared/i18n/index.ts)

여기서 하는 일:
- `ko`, `en`, `ja`, `zh` 리소스 등록
- 기본 언어 `ko` 설정
- fallback 언어 `en` 설정
- namespace 등록
  - `common`
  - `nav`
  - `home`
  - `auth`
  - `form`
- `react-i18next` 연결

그래서 이 파일이 실행된 뒤에는:
- `useTranslation()` 사용 가능
- `t('common:signIn')` 사용 가능
- `i18n.changeLanguage('en')` 사용 가능

## 프론트에서 가져다 쓰는 방식

### 기본 패턴

컴포넌트에서 이렇게 씁니다.

```tsx
import { useTranslation } from 'react-i18next'

export function Example() {
  const { t } = useTranslation()

  return <h1>{t('auth:login.title')}</h1>
}
```

설명:
- `useTranslation()`으로 번역 함수 `t`를 가져옴
- `t('namespace:key')` 형태로 등록된 문구를 꺼내 씀

## 언어 변경은 어디서 하나

- [language-select.tsx](/Users/terecal/mini-sns-conainer/mini-sns-front/src/shared/ui/language-select.tsx)

여기서는 `useTranslation()`에서 `i18n` 객체를 꺼내서 사용합니다.

핵심 코드:

```tsx
const { i18n } = useTranslation()

void i18n.changeLanguage(event.target.value)
```

즉:
- 사용자가 `ko`, `en`, `ja`, `zh` 중 하나를 선택
- `changeLanguage(...)` 실행
- 화면에서 `t()`로 렌더링하는 문구가 즉시 바뀜

## 중요한 이해 포인트

### 1. `@/shared/i18n`을 매번 import하는 게 아님

초기화는 `main.tsx`에서 한 번만 합니다.

그 후에는 대부분 컴포넌트에서 이렇게 씁니다.

```tsx
const { t } = useTranslation()
```

즉:
- 초기화 파일 직접 재사용 X
- 컴포넌트에서는 `useTranslation()` 사용 O

### 2. 직접 `i18n` 객체를 쓰는 경우도 있음

예:
- 언어 변경
- 컴포넌트 밖에서 번역 처리
- 테스트 코드

하지만 일반적인 화면 렌더링은 거의 `t()`를 통해 처리합니다.

### 3. 지금은 namespace 기준으로 쓰는 구조

현재는 아래처럼 namespace를 붙여서 쓰는 게 기준입니다.

예:
- `common:signIn`
- `nav:home`
- `home:title`
- `auth:signup.description`
- `form:email`
